# Thumbnail Prompts (for AI image generators)

These prompts describe `thumb_D_detailed_1280x720.jpg`. Use them in Midjourney, DALL·E / ChatGPT, Ideogram, Flux, Leonardo and similar tools.

**Tip:** AI tools often misspell text. Generate the image **without text**, then add "11:59 PM", "12:00 AM" and the tag in Canva or CapCut, or ask Ideogram for the text.

---

## Text-free version (add text later in Canva/CapCut)

```
Leave clean empty space at the top of both panels and in the bottom-right corner for text to be added later. No text, no letters, no numbers anywhere in the image.
```
