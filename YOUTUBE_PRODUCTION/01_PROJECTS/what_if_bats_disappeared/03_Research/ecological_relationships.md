# Ecological Relationships: Bats

```
Insect-eating bats ──eat──> crop pests (corn earworm / cotton bollworm, beetles, other moths)
        │                          │
        │ (WNS kills bats)         └─ fewer bats → more pests → more insecticide (+31%, S01)
        │                                                   └─ exposure → infant mortality +7.9% (S01)
Nectar bats ──pollinate──> agave (lesser long-nosed bat, S14), durian (cave nectar bat, S15), 500+ species (S13)
        └─ pollination keeps wild agave genetically diverse; cloned crops lack that diversity
Fruit bats ──disperse seeds──> pioneer plants in clearings → forest regrowth (S16)
Culling ──disrupts colonies──> rabies exposure not reduced, or higher (S17); Marburg infection higher after
recolonisation (S18)
Threats: white-nose fungus (S02–S06), wind turbines (S20); mitigation: curtailment (−62%), protected
caves, bat-friendly agave
```
